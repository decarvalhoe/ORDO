# External assessment pack — ORDO

> Languages: **EN** · [FR](README.fr.md) · [DE](README.de.md)

> This folder gathers **neutral inputs** for an independent external assessment
> of the ORDO project's state and value. It is written to enable an
> **impartial** analysis: verifiable facts, evidence, and known gaps. The
> repository **states no value verdict** and does not seek to steer the
> analyst's conclusion.

## Impartiality principle

1. **Facts, not persuasion.** Every statement maps to evidence: code, tests,
   CI, a generated artifact, or a named gap — per the "every claim maps to
   evidence" rule of [public-claim-boundary.md](../public-claim-boundary.md).
2. **No self-assessment.** The repository does not quantify its own value or
   place itself on a value scale. Valuation inputs are provided as neutral
   frameworks, for the analyst to apply.
3. **Reproducible.** Metrics are dated, anchored to a commit, and accompanied by
   verification commands.
4. **Neither oversold nor undersold.** The standard is truth; the delivered
   scope is clearly distinguished from the forward-looking scope (roadmap).
